Session files

A shared base folder and filename pattern for your session.

Choose an absolute folder path on the computer running Babel. The destination stays the same wherever Babel is launched. ~ and environment variables are not expanded.

{date} and {time} use UTC; {session} uses the session name adapted for a filename; {id} is the required unique identifier. Use only these placeholders, without directory separators. The .txt and .wav extensions are added automatically.
