Babel for Windows 10 and 11

This installer contains Babel and its local inference engines. Install
Virtual Cables separately on Windows x64:
https://github.com/tarekwasfy01/Virtual-Cables/releases

Use the signed usbip-win2 transport from its official releases and configure two
cables as described in docs\platforms.md. The Virtual Cables project documents
x64 support. The guide also covers existing VB-CABLE pairs.
Babel leaves the Windows default audio devices alone.

Babel's installer and portable executables are unsigned. Windows SmartScreen
can warn and Smart App Control or an organization policy can block them.
The installer does not change any system security settings.

Open Babel from the Start menu. Settings are in the tray and open in your
browser. Configuration is stored in %APPDATA%\Babel\babel.toml. Recordings
and transcripts are stored in the folder you select in Babel. Uninstalling
Babel preserves user files and keeps separately installed audio devices.
