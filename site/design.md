# Website direction

Babel is an audio workspace, so the central visual is a two-way signal path,
not an abstract AI illustration. A small interactive routing preview explains
how translation, transcription, and recording remain independent.

- Palette: paper `#ffffff`, sky `#edf3ff`, ink `#182744`, Babel blue `#345cf4`,
  incoming-audio teal `#087f83`, secondary text `#596b84`.
- Type: the repository's self-hosted Manrope variable font; large, compact
  headlines and readable documentation with a restrained line length.
- Layout: left-aligned opening statement and a wide audio console; generous
  white space; feature explanations grouped by the actual workflow rather than
  identical cards. The documentation shares the same navigation and typography.
- Interaction: explicit demo switches change the signal path and explain the
  result. No microphone permissions, animation loops, analytics, or external
  client-side dependencies. Respect reduced motion and keyboard navigation.

The initial generic card grid was rejected in favor of a single prominent
signal console and quiet editorial feature rows. The console carries the
visual identity; everything else helps visitors evaluate, install, or use Babel.
